Date: 2026-11-08. Target: Ubuntu 24.04 LTS, GNOME Shell 46, Wayland first.

## Status

- static/unit/schema/assets/XDG isolation: verified
- runtime GNOME 46/Wayland: pending
- runtime GNOME 46/X11: pending
- release status: pre-release; no stable or runtime-compatible claim

## Scope and evidence

This release preserves all v0.5.1 functionality while reconciling the historical
bootstrap specification. It adds contributor guidance and a bootstrap contract,
synchronizes version 9 / 0.5.2, and moves optional Nautilus prerequisite checks
before installer writes. The detailed inventory, gaps and historical acceptance
mapping are in `docs/verification/v0.0.1.md`.

## Known limitations

- No live GNOME 46 enable/disable or graphical interaction has been established
  by repository tests.
- Mid-copy I/O failure can still leave a partial install; environment and
  optional dependency rejection now occur before the first destination write.
- GNOME Shell internal JavaScript APIs remain version-specific behind the
  compatibility module.

## Manual validation

Follow the GNOME 46 lifecycle and uninstall checklist in
`docs/verification/v0.0.1.md`, then exercise the v0.5.1 feature matrix in
`docs/verification/0.5.1.md` to catch regressions in taskbar, popups, services,
window workflows, appearance, DING and Nautilus.

## Rollback

Disable WinShell and run `./scripts/uninstall.sh`. If returning to v0.5.1, install
a reviewed v0.5.1 artifact after removal. Do not force appearance restoration
until any reported external changes have been inspected.
