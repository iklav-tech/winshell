## Scope and evidence

This release preserves v0.5.3 while reconciling system panels, calendar,
context actions and notifications. It capability-gates notification actions,
guards internal Shell signals, distinguishes unavailable source enumeration from
an empty list, adds a SPEC contract and synchronizes version 11 / 0.5.4. The
support matrix and historical acceptance mapping are in
`docs/verification/v0.2.0.md`.

## Known limitations

- No panel or service interaction from this artifact has been exercised inside
  the live GNOME Shell process.
- MessageTray and GVC JavaScript contracts are internal to GNOME Shell 46;
  feature detection prevents unsupported actions but does not certify semantics.
- Hardware/service availability, permission failures, notification residency,
  multi-monitor scaling and lifecycle leaks require manual validation.
- New Wi-Fi credentials, Bluetooth pairing and advanced configuration remain in
  GNOME Settings by design.

## Manual validation

Follow the complete service, calendar, context, notification, monitor and
lifecycle checklist in `docs/verification/v0.2.0.md`, then exercise the v0.5.3
checklist to catch regressions in shell foundation and later features.

## Rollback

Disable WinShell and run `./scripts/uninstall.sh`. To return to v0.5.3, install a
reviewed v0.5.3 artifact afterward. Inspect any appearance divergence before
using forced restoration.
