- static/unit/schema/assets/XDG isolation: verified

## Scope and evidence

This release preserves all v0.5.2 functionality while reconciling the
historical shell-foundation specification. It adds a tested pure model for Start
search, pinned ordering, pin toggling and taskbar click decisions; identifies
running applications in Start; and synchronizes version 10 / 0.5.3. The detailed
inventory and acceptance mapping are in `docs/verification/v0.1.0.md`.

## Known limitations

- No live GNOME 46 enable/disable or graphical interaction has been established
  by repository tests.
- Running-state layout and accessible announcement need manual validation with
  long app names, scaling and assistive technology.
- GNOME Shell internal JavaScript APIs remain version-specific behind the
  compatibility module.
- Mid-copy I/O failure can still leave a partial user-local install.

## Manual validation

Follow the taskbar, Start, preferences and lifecycle checklist in
`docs/verification/v0.1.0.md`, then exercise the v0.5.2 feature matrix in
`docs/verification/0.5.2.md` to catch regressions in system panels, windows,
appearance, DING and Nautilus.

## Rollback

Disable WinShell and run `./scripts/uninstall.sh`. If returning to v0.5.2,
install a reviewed v0.5.2 artifact after removal. Do not force appearance
restoration until any reported external changes have been inspected.
