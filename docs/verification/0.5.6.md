## Scope and evidence

This release preserves v0.5.5 while reconciling the graphical Snap picker. It
adds reusable immutable template validation, exact normalized/pixel coverage,
per-region client-constraint eligibility, explicit unavailable/empty states and
generated interaction styling. It also guards source-less stage clicks observed
in a separately installed copy, then synchronizes integer version 13 / 0.5.6.
The historical acceptance mapping is in `docs/verification/v0.4.0.md`.

## Known limitations

- No Snap diagram or window movement from this artifact has been exercised
  inside GNOME Shell 46; focus/hover/disabled visuals remain pending.
- Native Wayland and XWayland clients may apply size hints or settle their frame
  after the existing 160 ms observation window.
- Fractional scaling, small monitors, fullscreen, taskbar struts and monitor
  hotplug while the picker is open need visual/runtime evidence.
- Snap selects one window/region and intentionally does not fill remaining
  regions or create persistent Snap groups.

## Manual validation

Run the nine-step graphical Snap, constraints, keyboard, multi-monitor and
lifecycle checklist in `docs/verification/v0.4.0.md`, then repeat the v0.5.5
window-workflow checklist to catch regressions.

## Rollback

Disable WinShell and run `./scripts/uninstall.sh`. To return to v0.5.5, install a
reviewed v0.5.5 artifact afterward. No GSettings migration is required because
this release preserves every key and default.
