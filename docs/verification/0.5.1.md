Date: 2026-11-08. Target: Ubuntu 24.04 LTS, GNOME Shell 46, Wayland first.

## Status

- static/unit/schema/assets/XDG isolation: verified
- runtime GNOME 46/Wayland: pending
- runtime GNOME 46/X11: pending
- release status: pre-release; do not mark stable without the runtime evidence above

## Existing state and gaps found before implementation

The workspace already contained the v0.5.0 appearance release on top of v0.4.2.
Taskbar, Start, hardware controls, calendar, notifications, Snap Layouts,
multi-monitor handling, reversible dock conflict policy and appearance packages
were implemented but had no recorded live GNOME acceptance. The baseline
`./tests/check.sh` stopped in generated-asset verification because declared
terminal/settings artwork and derived aliases were absent from the workspace;
the first reported missing file was `utilities-terminal.svg`.

SPEC 00 gaps with direct regression potential were:

- Shell-owned chrome depended on actor destruction instead of explicit removal;
- GNOME Shell internal APIs were imported across several feature modules;
- popup positioning and monitor selection were embedded in GJS and untested;
- popup focus started on a container and was not restored to the invoking control;
- a partial taskbar rebuild could retain bars created before a later failure.

## Manual GNOME 46 validation

1. Install in a disposable user profile, sign out/in on Wayland, then enable the
   extension and keep `journalctl --user -f | grep -i winshell` open.
2. Repeat enable/disable ten times. Confirm no WinShell actors, focus grabs,
   timeouts, signals, struts or hidden native panel remain after disable.
3. Open every popup by mouse and keyboard. Traverse with Tab/Shift+Tab, close via
   Escape and outside click, and confirm focus returns to the invoking taskbar item.
4. Exercise a negative-origin secondary monitor, 100%, 125%, 150% and 200% scale,
   monitor hotplug, fullscreen on each display and the zero-monitor transition.
5. Exercise NetworkManager, Bluetooth, audio, brightness, UPower and permission /
   missing-service failures without blocking or disabling unrelated controls.
6. Verify notifications, calendar locale, Snap windows on Wayland and XWayland,
   dock conflict restore, Light/Dark/system appearance, DING and Nautilus.
7. Repeat the smoke test in X11 and record every behavioral difference here.

## Known limitations

- Live GNOME rendering, API behavior, accessibility tooling and leak checks cannot
  be established by Node/static tests.
- MessageTray, GVC, Slider and extension-manager JavaScript APIs remain tied to
  GNOME Shell 46; the compatibility boundary reduces but does not remove that risk.
- No translation catalog is shipped yet; date/time/calendar formatting follows the
  active locale, while interface strings remain the current project language.

## Rollback

For an installed v0.5.1 copy, first disable the extension so runtime state and any
WinShell-managed dock are restored:

```bash
gnome-extensions disable winshell@iklav-tech
./scripts/uninstall.sh
```

The uninstaller restores tracked appearance before removing WinShell-owned files
and stops on external changes. Review conflicts before using `--force-restore`;
use `--no-restore` only when intentionally keeping the current appearance. To
return to v0.5.0, install a reviewed v0.5.0 artifact after the v0.5.1 uninstall.
The appearance backup remains under `$XDG_CONFIG_HOME/winshell` for recovery.
