## Scope and evidence

This release preserves v0.5.4 while reconciling window previews, constrained
Snap operations, monitor topology and native notification ownership. It adds
client-size and final-frame validation, non-focusing hover with a keyboard entry
path, explicit minimized-window handling and focused contracts, then synchronizes
integer version 12 / 0.5.5. The historical acceptance mapping is in
`docs/verification/v0.3.0.md`.

## Known limitations

- No taskbar, preview, Snap, hotplug or notification interaction from this
  artifact has been exercised inside GNOME Shell 46.
- The 160 ms compositor-result observation needs validation with slow native
  Wayland and XWayland clients; applications can still enforce unusual geometry.
- Hover timing, focus traversal, fractional scaling, fullscreen and strut
  behavior require visual/runtime evidence on real monitor topologies.
- MessageTray remains an internal GNOME Shell 46 interface with guarded
  fallbacks, not a cross-version public persistence API.
- Snap Layouts select one window/region; automatic filling of remaining regions
  is intentionally outside this release.

## Manual validation

Run the complete ten-step Wayland/X11 window, preview, hotplug, notification and
lifecycle checklist in `docs/verification/v0.3.0.md`, then repeat the v0.5.4
system-panel checklist to catch regressions.

## Rollback

Disable WinShell and run `./scripts/uninstall.sh`. To return to v0.5.4, install a
reviewed v0.5.4 artifact afterward. Inspect any appearance divergence before
using forced restoration.
