# WinShell — SPEC 0.2.0 system-panels reconciliation

Date: 2026-11-08. Historical target: Ubuntu 24.04 LTS, GNOME Shell 46,
Wayland first. Reconciled in repository release v0.5.4 without downgrading or
removing newer functionality.

## Status

- static/unit/schema/XDG isolation: verified in the v0.5.4 reconciliation
- runtime GNOME 46/Wayland: pending
- runtime GNOME 46/X11: pending
- historical v0.2.0 release claim: unsupported; no contemporary runtime evidence
  establishes the originally partial release as complete

## Existing functionality, gaps and changes

The inspected repository started at v0.5.3 (integer 10). Work completed after
the historical v0.2.0 point already provided real NetworkManager Wi-Fi,
gnome-bluetooth/rfkill, GVC audio/output, Settings Daemon brightness, UPower
battery, DND and color-scheme state. It also had a 6×7 locale-aware calendar,
capability-aware app/window context actions, a MessageTray-backed notification
center, light/dark styling, preferences, pure models and monitor-clamped popup
geometry.

The remaining reconciliation gaps were:

- source/notification signals from internal Shell APIs were connected without a
  guarded fallback, so a missing signal could abort taskbar construction;
- notification cards always exposed activation/dismiss controls based on the
  expected GNOME 46 shape instead of projecting the callbacks actually present;
- an unavailable MessageTray source enumeration looked identical to a valid
  empty notification list;
- there was no focused SPEC 0.2.0 contract or historical acceptance artifact.

v0.5.4 adds capability projection, guarded signal connections, an explicit
unsupported source state and focused static/unit coverage. It introduces no
GSettings migration and preserves later window, appearance and desktop features.

## Potential regressions and mitigations

- Guarded signal connection can reduce live refresh if a Shell signal is absent;
  reopening always rebuilds the authoritative snapshot, and runtime validation
  must record which GNOME 46 signals are present.
- Capability filtering can hide an action previously rendered optimistically;
  this is intentional because a nonfunctional control is not acceptable.
- MessageTray/GVC remain internal/version-specific despite the compatibility
  boundary. Metadata remains restricted to Shell 46.
- Service adapters and hardware combinations cannot be exhaustively represented
  by unit fixtures; unavailable/error states remain visible and isolated.
- Popup geometry is tested for negative origins and fractional anchors, but real
  scaling, work areas and hotplug still require Shell validation.

## Manual GNOME 46 validation

1. Install v0.5.4 in a disposable Ubuntu 24.04 Wayland profile and inspect the
   journal while opening/closing both panels on every configured monitor.
2. Toggle DND and dark mode; verify external changes update both panels.
3. Toggle Wi-Fi/Bluetooth, scan, activate a known Wi-Fi profile, connect a paired
   device, and verify new/pairing flows open the correct GNOME Settings panel.
4. Change volume, mute, output and brightness; unplug/replug devices where safe
   and confirm unavailable/error states do not close the extension.
5. Navigate December/January and leap-year February, select adjacent-month days,
   switch locale, and test keyboard focus/Escape restoration.
6. Exercise pin, new-window, window activation, minimize/maximize and close only
   where the application advertises those capabilities.
7. Generate, update, activate and dismiss notifications with and without actions
   from several apps; test DND, resident and critical notifications.
8. Enable/disable ten times and hotplug a monitor. Confirm all signals, idles,
   actors, chrome and service references are released.
9. Repeat feasible checks on X11 and record differences.

## Rollback

```bash
gnome-extensions disable winshell@iklav-tech

```

Review appearance conflicts before forcing restoration. Returning to v0.5.3
requires installing a reviewed v0.5.3 artifact after removal; this reconciliation
adds no schema key or data migration.
