Date: 2026-11-08. Historical target: Ubuntu 24.04 LTS, GNOME Shell 46,
Wayland first. Reconciled in repository release v0.5.3 without downgrading or
removing newer functionality.

- historical v0.1.0 release claim: unsupported; no tag or contemporary runtime

## Existing functionality, gaps and changes

The inspected repository started at metadata v0.5.2 (integer 9). It already had
a bottom, monitor-aware taskbar with centered/left alignment; pinned and running
applications; real launch, activation and focused-window minimization; a Start
application list with search and empty state; clock/date; a native WinShell
calendar; GTK4/Libadwaita preferences backed by GSettings; optional native-panel
coexistence; and explicit actor, chrome, signal, service and timeout cleanup.

The gaps found against the retrospective SPEC were:

- search, pinned-first ordering, pin/unpin and activate/minimize decisions were
  embedded in Shell UI code and had no focused pure unit contract;
- the Start list did not identify which applications were already running;
- there was no historical v0.1.0 verification document separating source/test
  evidence from live GNOME acceptance.

Release v0.5.3 extracts those decisions to `shellFoundationModel.mjs`, consumes
them from Start, taskbar and context-menu code, adds unit coverage, and renders
an accessible “Em execução” state in Start. No GSettings keys changed.

## Potential regressions and mitigations

- Search still uses name, description, executable and keywords and retains
  pinned-first/name ordering; tests cover every field and the empty result.
- The new running label consumes horizontal Start-list space. Check long names,
  translations and 100%/125%/150%/200% scaling manually.
- Taskbar click behavior is unchanged but now passes through a pure decision;
  tests cover focused, minimized and unrelated-window states.
- Pinning keeps the existing string-array contract and removes duplicate IDs on
  unpin. Existing user values need no migration.
- All v0.2.0–v0.5.2 modules remain present. Metadata advances to v0.5.3 instead
  of rewriting the repository as historical v0.1.0.
- Static checks cannot prove focus behavior, Shell lifecycle cleanup or
  persistence across a graphical session restart.

## Manual GNOME 46 validation

1. Install in a disposable Ubuntu 24.04 user profile, sign out/in on Wayland and
   enable `winshell@iklav-tech`.
2. Toggle centered/left alignment and verify taskbar placement with the native
   panel both shown and hidden.
3. Open Start by pointer and keyboard, search using name, description,
   executable and keyword, launch with click/Enter, and verify the empty state.
4. Confirm a running app is announced and shown as “Em execução”; verify long
   names and 100%/125%/150%/200% scaling.
5. Pin and unpin an app, restart the session, and confirm order/persistence.
6. With one and several windows, click the taskbar icon to switch, minimize the
   focused window and restore/activate it. Repeat with minimized windows.
7. Open clock/calendar, use keyboard navigation and close with Escape/outside
   click; confirm focus returns to the prior control.
8. Change preferences, restart the session and confirm GSettings persistence.
9. Enable/disable ten times while inspecting the journal. Confirm no WinShell
   actor, strut, popup, signal, timeout or hidden panel remains after disable.
10. Repeat feasible checks on X11 and record behavioral differences.

## Rollback

For an installed copy:

```bash
gnome-extensions disable winshell@iklav-tech
./scripts/uninstall.sh
```

The uninstaller restores tracked appearance and only removes WinShell-owned
user-local paths. Review any external-change warning before forcing appearance
restoration. To return specifically to v0.5.2, install a reviewed v0.5.2 artifact
after uninstalling v0.5.3; no schema migration or data conversion is needed.
